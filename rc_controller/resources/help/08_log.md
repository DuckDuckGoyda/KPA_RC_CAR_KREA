# Журнал и эхо-тест

## Журнал

Каждая строка — отправленный пакет (→), принятый (←) или событие (•).

| Столбец | Содержимое |
|---|---|
| Время | с точностью до миллисекунд |
| Источник | терминал, движение, опрос, макрос, стоп, эхо-тест, связь |
| SQN | номер пакета — по нему ответ связан с запросом |
| Содержание | команда в понятном виде (`SS_SA speed=50 angle=-20`) или расшифровка ответа |
| Байты | пакет целиком в HEX |
| Статус | принята / отказ / таймаут / эхо / опоздал / ошибка CRC … |
| RTT | время от отправки до ответа, мс |

Галочки сверху скрывают частые записи (движение, опрос); поиск ищет по тексту, статусу и байтам. «Сохранить…» — выгрузка в CSV для Excel.

**Журнал сеанса** пишется автоматически в папку `logs` (имя файла — внизу окна). При нештатной ситуации этот файл нужно отправить разработчику — в нём весь обмен.

## Эхо-тест

Текущее требование к проекту — машинка должна возвращать всё, что получила по UART. Вкладка **Эхо-тест** проверяет это автоматически:

1. Подключитесь (USB или Bluetooth), прошивка — в режиме эха.
2. Задайте число блоков, размер, паузу и время ожидания.
3. **Начать.** Каждый блок отправляется и сравнивается с ответом байт в байт.

Результат: сколько блоков совпало, исказилось, потерялось, и время отклика **RTT** (мин / сред / макс). Сравнив RTT по USB и по Bluetooth, можно узнать реальное время реакции машинки (требование — не более 50 мс).

Во время теста опрос связи и команды движения приостанавливаются, итог записывается в журнал.
