# Быстрый старт

**RC Controller** — пульт управления машинкой с ноутбука. Связь идёт по UART: через USB-кабель (USB-UART переходник или виртуальный COM-порт STM32) или по Bluetooth через модуль HC-05. Для программы оба варианта — это просто COM-порт.

## Подключение

1. Включите машинку. Для USB — подключите кабель. Для Bluetooth — один раз выполните сопряжение с HC-05 (см. раздел «Bluetooth и HC-05»).
2. В строке **Порт** выберите COM-порт. Рядом с каждым портом написано, что это: **USB** или **Bluetooth**. Список обновляется при раскрытии или кнопкой ⟳.
3. **Скорость** — 19200 бод. Её можно поменять, например 38400 для настройки HC-05 AT-командами.
4. Нажмите **Подключить**.

## Индикаторы

- **Плашка USB / Bluetooth** — через что идёт связь прямо сейчас.
- **Кружок и надпись:**
  - серый — нет подключения;
  - жёлтый — порт открыт, но машинка ещё не ответила;
  - зелёный — машинка отвечает;
  - красный — связь потеряна (несколько запросов подряд без ответа).
- **RTT** — среднее время «запрос → ответ»; также счётчики пакетов и ошибок (подробности во всплывающей подсказке).
- **Опрос связи** — периодически отправлять запрос из профиля (раз в секунду), чтобы следить за связью. Для эхо-теста и AT-команд удобнее выключить.

## Вкладки

- **Журнал** — все отправленные и принятые пакеты в расшифрованном виде.
- **Терминал** — ручная отправка команд протокола, текста (AT-команды) и произвольных байт.
- **Макросы** — заранее записанные маршруты: «вперёд 1,5 с, тормоз, назад 1,5 с».
- **Эхо-тест** — проверка, что машинка возвращает всё, что получила (текущее требование к проекту).

Слева — панель **Управление**: клавиши WASD, геймпад, ограничение скорости и большая кнопка **СТОП**.

## Проверка без машинки

Введите в поле порта `loop://` и нажмите «Подключить». Это виртуальная «петля»: всё отправленное сразу возвращается обратно — как машинка с прошивкой-эхом. Так можно попробовать терминал, эхо-тест и макросы без железа.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| W A S D | движение (работает и в русской раскладке) |
| Пробел, Esc | аварийная остановка |
| F1 | эта справка |
| Ctrl+R | перезагрузить профиль после правки |
| F5 / Ctrl+S | запустить / сохранить макрос (во вкладке «Макросы») |
