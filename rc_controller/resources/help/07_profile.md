# Профиль

Всё, что зависит от прошивки машинки, собрано в одном текстовом файле — **профиле** (`profiles/*.toml`). Код программы менять не нужно.

**Как править:** «Профиль → Открыть файл профиля в редакторе», сохранить, затем **Ctrl+R** («Перезагрузить профиль»). Если в файле ошибка, программа покажет, где именно (например, `command[3].params[1].type: недопустимое значение «int9»`), и продолжит работать со старым профилем.

Профилей может быть несколько (например, для разных машинок или версий прошивки) — переключаются в меню «Профиль».

## Разделы

| Раздел | Что задаёт |
|---|---|
| `[profile]` | название и описание |
| `[link]` | скорость UART, ожидание ответа, повторы, опрос связи |
| `[packet]` | синхрослово, адрес, SQN, порядок байт, вариант CRC |
| `[acks]` | расшифровка кодов подтверждения |
| `[[command]]` | команды: имя, код, параметры, разбор ответа |
| `[drive]` | что отправлять при движении, стоп и тормоз, максимумы, плавность |
| `[keys]` | клавиши управления |
| `[gamepad]` | раскладка геймпада |

## Добавить команду

```toml
[[command]]
name = "HORN"
code = 0x10
params = [{ name = "ms", type = "uint16", description = "длительность, мс" }]
description = "Посигналить"
```

Типы параметров: `int8`, `uint8`, `int16`, `uint16`, `int32`, `uint32`; `min` и `max` необязательны. После перезагрузки команда сразу доступна в терминале (`HORN 500`), в макросах (`команда HORN 500`) и в справке.

Разбор данных ответа — список `reply` с теми же типами, например у `GET_TEL`.

## Движение

```toml
[drive]
mode = "speed_angle"                  # или "differential"
command = ["SS_SA {speed} {angle}"]   # или ["SET_SPEED {speed}", "SET_ANGLE {angle}"]
stop = ["SS_SA 0 0"]
brake = ["SS_SA 0 0"]
max_speed = 127
max_angle = 127
invert_angle = false
```

Переменные в шаблонах: `{speed}`, `{angle}` (руль) или `{left}`, `{right}` (два борта). Шаблоны проверяются при загрузке — например, `max_speed = 200` при параметре `int8` сразу даст ошибку.

Если машинка поворачивает не туда — `invert_angle = true`; едет назад вместо вперёд — `invert_speed = true`.
