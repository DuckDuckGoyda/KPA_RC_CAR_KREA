# Макросы

Макрос — это маршрут, записанный простым текстом: по одному действию в строке. Файлы лежат в папке `macros` (меню «Файл → Открыть папку макросов») и редактируются прямо во вкладке **Макросы**. Ошибки подсвечиваются сразу, с номером строки.

## Пример

```
# Туда и обратно
вперёд 1.5 скорость=80
тормоз
назад 1.5 скорость=60 угол=-30
```

## Действия

| Действие | Что делает |
|---|---|
| `вперёд 1.5 скорость=80 угол=-20` | ехать вперёд 1,5 с. Скорость 0…100 %, угол −100…100 % (минус — влево) |
| `назад 2` | ехать назад 2 с |
| `стоп 1` | остановиться и стоять 1 с (`стоп` без времени — просто остановиться) |
| `тормоз 0.5` | торможение: команда `drive.brake` из профиля, по умолчанию 0,5 с |
| `пауза 1` | ничего не отправлять 1 с |
| `скорость 70` | скорость по умолчанию для следующих шагов, % (изначально 50 %) |
| `команда LED 0` | отправить любую команду протокола (синтаксис как в терминале) |
| `текст "AT\r\n"` | отправить строку как есть |
| `hex AC 53 04` | отправить байты |
| `повтор 3` … `конец` | повторить блок; блоки можно вкладывать |
| `# …` | комментарий |

Время: `1.5`, `1,5`, `1.5с`, `2сек`, `500мс`. Английские слова тоже работают: `forward`, `backward`, `stop`, `brake`, `wait`, `speed`, `send`, `text`, `hex`, `repeat`, `end`; параметры — `speed=`, `angle=`.

## Как выполняется

- Шаги движения выполняются друг за другом без пауз: `вперёд 1` и сразу `назад 1` — это разворот направления без остановки.
- Во время шага команда движения повторяется каждые `resend_ms`, как при езде с клавиатуры.
- Скорость в процентах умножается на ползунок «Ограничение скорости».
- **Прерывают макрос:** любая клавиша управления, движение геймпада, Esc, Пробел, кнопка «Стоп», отключение порта или потеря связи.
- **В конце** (и при прерывании) машинке всегда отправляется остановка.
- Во время выполнения текущая строка подсвечивается, внизу — номер шага и прогресс.

## Про тормоз

Пока механика не собрана, `тормоз` отправляет то же, что и стоп (`SS_SA 0 0`). Когда станет понятно, как тормозить (например, коротким импульсом назад), достаточно поменять в профиле строку `brake`:

```
brake = ["SS_SA -60 0"]
```

— и все макросы начнут тормозить по-новому.
