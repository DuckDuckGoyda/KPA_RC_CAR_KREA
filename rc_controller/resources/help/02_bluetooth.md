# Bluetooth и HC-05

## Сопряжение в Windows (один раз)

1. Включите машинку: светодиод HC-05 часто мигает — модуль ждёт подключения.
2. **Параметры → Bluetooth и устройства → Добавить устройство → Bluetooth**.
3. Выберите **HC-05** (или имя, заданное командой `AT+NAME`). PIN-код по умолчанию — **1234** (у некоторых модулей **0000**).
4. Windows создаст **два** COM-порта. Нужен **исходящий**:
   в программе у него указан адрес модуля (`Bluetooth 98:D3:…`), а у входящего — пометка «входящий — не подойдёт».
   Посмотреть вручную: **Панель управления → Устройства и принтеры → Дополнительные параметры Bluetooth → вкладка «COM-порты»**, направление «Исходящий».

При нажатии «Подключить» Windows устанавливает Bluetooth-соединение — это может занять несколько секунд. Когда связь установлена, светодиод HC-05 мигает редко (или горит).

## Настройка HC-05 AT-командами

Протокол требует **19200 бод, 8N1**, а у нового модуля обычно 9600 или 38400. Скорость настраивается один раз:

1. Подключите HC-05 к компьютеру через USB-UART переходник (TX → RX, RX → TX, GND, питание).
2. Войдите в **AT-режим**: подайте на вывод **KEY** (PIO11, 34-я ножка) высокий уровень **до** подачи питания (на многих платах — зажать кнопку при включении). Светодиод мигает медленно, раз в 2 секунды.
3. В программе выберите порт переходника, скорость **38400**, подключитесь.
4. Выключите **Опрос связи**. Во вкладке **Терминал** справа есть готовые AT-команды — двойной щелчок вставляет команду, режим «Текст» с окончанием `\r\n` выбирается сам.
5. Отправьте `AT` — должен прийти `OK`. Затем `AT+UART=19200,0,0` и при желании `AT+NAME=…`, `AT+PSWD=…`. Роль должна быть `AT+ROLE=0` (ведомый).
6. Снимите высокий уровень с KEY и перезапустите модуль.

AT-команды пишутся **заглавными** буквами и заканчиваются `\r\n`. Полный список — в `docs/datasheets/HC-05_AT_Commands.pdf`.

## Если не подключается

- **Порт открывается очень долго или с ошибкой** — выбран входящий порт, машинка выключена или далеко, либо модуль уже подключён к другому устройству (телефону).
- **«Отказано в доступе» / порт занят** — порт открыт другой программой (терминал, IDE). Закройте её.
- **Приходит мусор** — не совпадает скорость UART между HC-05 и микроконтроллером (или прошивка ждёт другую скорость). В режиме Bluetooth скорость в программе на связь не влияет: она задана внутри HC-05.
- **Связь рвётся** — проверьте питание HC-05: при просадке напряжения от моторов модуль перезагружается.
