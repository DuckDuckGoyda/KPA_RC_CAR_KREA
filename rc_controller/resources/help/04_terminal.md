# Терминал

Терминал отправляет в порт то, что вы введёте. Режим выбирается слева от строки ввода.

## Режим «Команда»

Команда протокола по имени из профиля и её параметры через пробел:

```
SS_SA 50 -20
SET_SPEED 0x40
GET_TEL
VERSION 0
```

Программа сама собирает пакет: синхрослово `AC 53`, длину, номер SQN, адрес, CRC — и ждёт ответ. Результат (подтверждение, данные, время ответа) виден во вкладке **Журнал**.

Можно отправить и команду, которой нет в профиле: начните строку с числа — все числа станут байтами поля CMD (первое — код команды):

```
0x05 1 2       →  CODE = 0x05, PARAM = 01 02
```

Числа: десятичные (`10`, `-5`), шестнадцатеричные (`0x1F`), двоичные (`0b101`). Имена команд подсказываются при вводе.

## Режим «Текст»

Строка уходит как есть, в конец добавляется выбранное окончание (`\r\n` для AT-команд HC-05). Внутри строки работают `\r`, `\n`, `\t` и `\xNN` (любой байт).

## Режим «HEX»

Произвольные байты в шестнадцатеричном виде: `AC 53 04 00 01 04 AB`. Пробелы, запятые и `0x` можно не писать. Так удобно проверять реакцию прошивки на битые пакеты.

## Приём

Всё, что приходит из порта, показывается в окне терминала. Переключатель «Приём»:

- **Авто** — текст (например, ответы AT) показывается текстом, пакеты протокола и прочие двоичные данные — в HEX;
- **Текст** — всё как текст, непечатаемые байты показаны как `⟨1B⟩`;
- **HEX** — всё в шестнадцатеричном виде.

Расшифровка пакетов — во вкладке «Журнал».

## Удобства

- **↑ / ↓** — история введённых команд.
- Справа — **быстрые команды**: все команды профиля и AT-команды HC-05. Двойной щелчок вставляет команду в строку ввода.
- Пока курсор в строке ввода, клавиши WASD печатают текст. **Esc** — вернуть управление машинкой.
